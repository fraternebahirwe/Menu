# 🍳 Simple Omelette Recipe Card

> A clean, modern, and fully responsive recipe card component featuring preparation times, ingredients, step-by-step cooking instructions, and a nutritional breakdown table.

## ✨ Features & Component Breakdown

- **Hero Recipe Visual:** Dedicated header banner image (`images.png`).
- **Preparation Time Summary:** Distinct overview highlighting total time, prep time, and cooking duration.
- **Ingredients List:** Bulleted checklist including basic essentials and optional fillings.
- **Ordered Instructions:** Sequential 6-step cooking guide with bolded action points for optimal readability.
- **Nutritional Values Table:** Structured breakdown listing Calories, Carbs, Protein, and Fat per serving.
- **Accessibility (a11y):** Screen-reader accessible table captions (`.sr-only`), semantic landmarks (`<main>`, `<article>`, `<header>`, `<section>`), and `aria-labelledby` linkages.

---

## 🛠️ Built With

- **HTML5:** Semantic architecture, ordered/unordered lists, and clean data tables.
- **CSS3:** Custom card layout styling and responsive design (`omelette.css`).
